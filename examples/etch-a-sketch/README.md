# Etch-a-sketch
- Tested w/ OSC Bridge app on Windows 11 & Zig Sim free on iOS
- __NOT tested with Zig Sim pro__ - may require updated OSC routed addresses in sketch.js

## Usage
- Zig Sim setup
    - Enable "2D Touch", "Accel" and "Touch Radius" sensors
    - Use computer IP address and port 4242 in Zig Sim settings, 60fps recommended
- Ensure both devices are on the same WiFi network
- Start Zig Sim stream & OSC Bridge app
- Touch phone screen to draw on the computer canvas, press harder for thicker lines!
- Shake the phone to clear the canvas!
