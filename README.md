# OSC Bridge

OSC Bridge is a standalone Electron app that connects browser-based desktop sketches, phones, and Open Sound Control software on the same local network.

Version 2 adds a built-in phone controller, QR pairing, iPhone motion support, configurable OSC forwarding, diagnostics, recording, automated tests, and **Palm Cove Table Tennis**, an original motion-controlled table-tennis game. A separate phone app such as Zig Sim is no longer required for the standard controller workflow.

Original project by [Yonatan Rozin](https://yonatanrozin.com/project/osc-bridge/). Version 2 enhancements are maintained in this fork by Joshua Zamora.

## What it does

- Receives UDP OSC on port `4242` and forwards messages into the active desktop sketch.
- Hosts a secure phone controller on port `4244` and a guided setup page on port `4245`.
- Streams phone orientation, acceleration, rotation rate, touch, and buttons.
- Converts phone events into consistent `/phone/<device-id>/...` OSC addresses.
- Optionally forwards phone messages to another OSC program at `127.0.0.1:4243` by default.
- Records bridge traffic to newline-delimited JSON files.
- Reloads the desktop sketch automatically when its files change.
- Includes Palm Cove Table Tennis with configurable solo play and two-phone local multiplayer.

## Install and run from source

Requires Node.js 20 or newer.

```bash
npm install
npm start
```

The desktop dashboard opens full screen. Press `Esc` or `Ctrl/Cmd + F` to leave full screen.

## Connect an iPhone

Safari only exposes motion sensors to a trusted secure page, so OSC Bridge creates a local certificate authority and gives the iPhone a guided installation page. The root certificate remains the same when the computer's local IP address changes, so this normally happens only once per computer.

1. Put the iPhone and computer on the same Wi-Fi network.
2. Start OSC Bridge and scan the QR code on the desktop dashboard.
3. On the setup page, tap **Download certificate** and allow the profile download.
4. Open **Settings → General → VPN & Device Management**, select **OSC Bridge Certificate**, and tap **Install**.
5. Open **Settings → General → About → Certificate Trust Settings** and enable full trust for **OSC Bridge Local Root**.
6. Return to the setup page, open the motion controller, tap **Enable motion**, and approve Safari's sensor permission.

Only install the certificate generated by your own OSC Bridge computer. It can be removed later from **Settings → General → VPN & Device Management**.

### Firewall note

Allow private-network access so the phone can reach ports `4244` and `4245`. Allow UDP port `4242` when receiving OSC from other devices.

## Palm Cove Table Tennis

Select **Play Table Tennis** from the desktop dashboard. Palm Cove is a completely original clean-room implementation with original code, procedural visuals, synthesized sound, original opponents, and an original seaside-resort setting. It does not include or derive from Nintendo code, characters, branding, music, sounds, artwork, UI, dialogue, stages, or other protected assets.

### Solo

Choose one of four original opponents—Marina, Theo, Noa, or Vale—and set CPU difficulty from level 1 through level 5. Difficulty changes reaction time, movement speed, timing accuracy, placement, spin skill, power, and miss probability.

### Two players

Connect two real phones to the same OSC Bridge session. The first phone controls Player 1 and the second controls Player 2. Each player has independent handedness and calibration settings, and Player 2 can be mirrored for comfortable same-screen play.

### Motion and gameplay

- Orientation positions the racket and controls its face angle.
- Gyroscope and acceleration data identify deliberate forehand/backhand swings, speed, timing, aim, and spin.
- Shots support topspin, backspin, sidespin, directional placement, table bounces, net contact, legal serves, lets, alternating service, and win-by-two scoring.
- A three-step calibration records a ready position, forehand, and backhand for each human player.
- Motion assist, sensitivity, smoothing, handedness, volume, reduced motion, high contrast, and camera shake are adjustable.
- Touch, mouse, keyboard, and phone-button fallbacks keep the game playable when motion sensors are unavailable.
- Matches support quick, standard, and championship presets with instant rematches.

See [`docs/TABLE_TENNIS.md`](docs/TABLE_TENNIS.md) for full controls, physics, calibration, accessibility, multiplayer behavior, and troubleshooting.

The exact clean-room game source is stored as a local packaged bundle so the tested runtime and installer use identical bytes. Extract it for inspection with:

```bash
npm run extract:table-tennis
```

## Phone OSC addresses

Each connected phone receives a short session ID. Messages use this prefix:

```text
/phone/<device-id>
```

| Address | Arguments |
| --- | --- |
| `/phone/<id>/orientation` | `alpha, beta, gamma, absolute, screenAngle` |
| `/phone/<id>/quaternion` | `x, y, z, w` |
| `/phone/<id>/accel` | `x, y, z` |
| `/phone/<id>/accel-gravity` | `x, y, z` |
| `/phone/<id>/rotation-rate` | `alpha, beta, gamma` |
| `/phone/<id>/touch` | `x, y, pressure, phase, pointerId` |
| `/phone/<id>/button/a` | `pressed, value` |
| `/phone/<id>/button/b` | `pressed, value` |
| `/phone/<id>/status` | `event, detail` |

Touch coordinates are normalized from `0` to `1`. The phone's **Center racket** button zeroes the current orientation before future values are sent.

## Desktop sketch API

### Receive OSC

```js
const stop = OSC.route('/phone/*/touch', (args, address, metadata) => {
  const [x, y, pressure, phase] = args;
  console.log({ x, y, pressure, phase, address, metadata });
});

stop();
```

Patterns support `*` for one path segment and `**` for any remaining depth. Use `OSC.once(pattern, callback)` for a one-time route.

### Send OSC

```js
await OSC.send('/slider', 0.5);
await OSC.send('/color', [255, 100, 40], '192.168.1.50', 7000);
```

When the destination is omitted, OSC Bridge uses the output host and port selected on the dashboard.

### Bridge controls

```js
const status = await Bridge.getStatus();
await Bridge.startRecording();
await Bridge.stopRecording();
await Bridge.openSketchFolder();
await Bridge.openRecordingsFolder();
```

Existing sketches using `window.localIP` and `window.openSketchDir()` remain supported.

## Recording

Select **Start recording** on the dashboard or press `Ctrl/Cmd + Shift + R`. Recordings are saved as `.jsonl` files under `Documents/OSC Bridge Recordings`.

## Use a custom sketch

Press `Ctrl/Cmd + E` and replace the files in the opened `sketch` folder. The window reloads when a file changes. Examples in `examples/` can still receive ordinary UDP OSC from Zig Sim or other software.

## Ports and environment variables

| Purpose | Default | Override |
| --- | ---: | --- |
| UDP OSC input | `4242` | `OSC_BRIDGE_INPUT_PORT` |
| HTTPS phone controller | `4244` | `OSC_BRIDGE_CONTROLLER_PORT` |
| HTTP phone setup | `4245` | `OSC_BRIDGE_SETUP_PORT` |
| OSC output | `127.0.0.1:4243` | Desktop dashboard |

## Troubleshooting

### Enable motion is unavailable

Reopen the QR setup page, install the OSC Bridge profile, enable full trust under **Settings → General → About → Certificate Trust Settings**, then reopen the secure controller.

### The phone cannot open the setup page

Confirm both devices are on the same Wi-Fi network and private-network access is allowed through the computer firewall. Guest networks often block device-to-device traffic.

### The computer's IP address changed

Restart OSC Bridge. It creates a new server certificate for the current IP, signed by the same local root certificate already installed on the phone.
